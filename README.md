# Косметология клиникасы (React + Vite)

Бұл жоба — косметолог/косметология клиникасына арналған толық функционалды сайт.  
Технологиялар: React, Vite, React Router, TailwindCSS, Framer Motion, Axios, JSON Server.

## Іске қосу

1. Тәуелділіктерді орнату:
```bash
npm install
```

2. Mock API (json-server) іске қосу:
```bash
npm run server
```

3. Клиенттік қосымшаны іске қосу:
```bash
npm run dev
```

`http://localhost:5173` адресіне кіріңіз.  
API әдепкіде `http://localhost:5179`.

## Негізгі функционал
- Басты бет: клиника туралы, артықшылықтар, CTA.
- Қызметтер: категория фильтрі, іздеу, жазылу.
- Қызмет деталі: толық ақпарат, көрсетілім/қарсы көрсетілім, aftercare, FAQ.
- Бағалар және пакеттер.
- Біз туралы: портфолио/сертификат, галерея.
- Пікірлер.
- Контакт және карта.
- Онлайн жазылу формасы (мәлімет API-ға сақталады, LocalStorage backup бар).
- Админ панель: қызметтер, прайс-лист, пакеттер CRUD, жазылулар тізімі.

## PWA (телефонға орнату)
1. Сайтты ашыңыз (Chrome/Edge).
2. Адрес жолында “Install App” немесе “Add to Home Screen” таңдаңыз.
3. Иконка телефонда жеке қосымша сияқты пайда болады.
